# 线上对战边界问题修复（2026-10-07）

本轮按用户要求仅修复本地代码并同步 GitHub，不部署服务器。
线上服务保留此前部署的 `9ce6566`。

## 修复行为

- 房间超时清理时广播 `CLOSED` 并解除服务器连接的房间绑定。
  客户端清除旧身份、排队命令和对局表现，自动回到大厅，可在同一连接上创建新房间。
  重连返回房间不存在、令牌失效等不可恢复错误时也释放旧身份。
- 重连成功后重新检查双方的准备或重赛意愿，条件满足即开始对局。
  重赛仍创建新 match ID，并清除施法序列去重状态；重复重连不会重复创建对局。
- 正在运行的对局不因无操作被闲置清理；大厅及结束后的房间由客户端心跳刷新活跃时间。
  断线超过重连期限及真正闲置的大厅仍会清理。
- 成功连接或取得房间身份后清除旧错误。
- 清除房间后忽略迟到的旧快照和事件，避免旧对局状态重新出现在大厅。
