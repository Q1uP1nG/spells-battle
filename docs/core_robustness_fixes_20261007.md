# 核心判别边界修复（2026-10-07）

修复提交时仅同步源码至 GitHub，未部署服务器。
用户随后授权部署，公网已更新至运行代码 `a29dfcb`，使用协议 3。

- 手势特征和模板匹配共用坐标校验，接受二维 NumPy 数组和列表，拒绝
  NaN、Infinity、不规则列表、非数字及错误维度。非有限距离不参与决策。
- Incendio 必须朝对手方向推进。模板镜像容错不能绕过这条方向规则；
  左侧向右、右侧向左的正常划动仍可识别。
- 模板包加载校验点数、结构、标签、原型坐标和阈值；无效包不保留部分加载状态，
  默认管线可回退到运行时模板或规则判别。
- 同一帧双方被击倒时为平局：`winner=-1`，`round_ended` 仅发送一次，HUD 显示
  `DRAW`，可按正常流程请求重赛。`None` 仍表示尚未结束，0/1 表示胜者。
- 消息类型为数组、对象或其他非字符串时返回协议错误，不再进入内部异常分支。
